## 1042. Flower Planting With No Adjacent

Pattern: Graph + Greedy + Coloring

### 1. Approach

- Build an adjacency list to store garden connections.
- Initialize `ans = [0] * n` to store flower types.
- Iterate through gardens from `1` to `n`.
- For each garden:
  - Collect flower types already assigned to its neighbours using a `set`.
  - Check flower types from `1` to `4`.
  - Assign the first flower type not used by its neighbours.
- Return the answer array.

### 2. Pseudocode

```
Build adjacency list
Initialize ans with 0

For each garden i:
    Create an empty set called used

    For each neighbour:
        Add neighbour's assigned flower to used

    For flower from 1 to 4:
        If flower is not in used:
            Assign flower to garden i
            Break

Return ans
```

### 3. Code

```
from collections import defaultdictclass Solution:    def gardenNoAdj(self, n: int, paths: list[list[int]]) -> list[int]:        adjl = defaultdict(list)        for u, v in paths:            adjl[u].append(v)            adjl[v].append(u)        ans = [0] * n        for i in range(1, n+1):            used = set()            for neigh in adjl[i]:                used.add(ans[neigh-1])            for flower in range(1, 5):                if flower not in used:                    ans[i-1] = flower                    break        return ans
```

### 4. Complexity

| Complexity      | Explanation                                                     |
| --------------- | --------------------------------------------------------------- |
| Time: O(V + E)  | Build adjacency list and check at most 3 neighbours per garden. |
| Space: O(V + E) | Adjacency list, answer array and temporary set.                 |

### 5. Essentials to remember

1. Greedy coloring: Choose the first available flower type.
2. Only 4 flower types are available.
3. Each garden has at most 3 neighbours, so a valid flower is guaranteed.
4. `set()` stores flower types already used by neighbours.
5. `ans[neigh-1]` because garden numbering starts at 1, but array indexing starts at 0.
6. No BFS or DFS required.
7. Process gardens sequentially; previously assigned neighbours provide the constraints.

Interview takeaway: Unlike Bipartite Graph (785), which requires checking whether two-coloring is possible, this problem guarantees a valid coloring and can be solved using a simple greedy algorithm.
