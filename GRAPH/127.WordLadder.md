# LeetCode 127 — Word Ladder

**Pattern:** BFS + Word Transformation + Set + Visited

## Approach

1. **Convert `wordList` into a set**
   - `words = set(wordList)`
   - A set allows faster lookup to check whether a generated word exists.

2. **Handle base cases**
   - If `beginWord == endWord`, return `1`.
   - If `endWord` is not in `words`, return `0`, because no valid transformation sequence can reach it.

3. **Initialize BFS**
   - `que = deque([(beginWord, 1)])`
   - Each queue entry contains `(word, step)`.
   - `step = 1` because the sequence includes `beginWord`.
   - `visit = {beginWord}` prevents revisiting words.

4. **Process the queue**
   - Pop a word and its current sequence length.
   - If the word equals `endWord`, return `step`.

5. **Generate neighboring words**
   - Iterate through each character position using `i`.
   - Split the word into three parts:
     - `left = w[:i]` → characters before index `i`.
     - `ch` → the character that replaces the character at index `i`.
     - `right = w[i+1:]` → characters after index `i`.
   - Combine them to generate a new word:
     - `value = left + ch + right`

6. **Validate each generated word**
   - Check that `value` exists in `words`.
   - Check that `value` has not been visited.
   - Add it to the queue with `step + 1`.
   - Mark it visited immediately after adding it to the queue.

7. If the queue becomes empty without finding `endWord`, return `0`.

## Why do we use `left = w[:i]` and `right = w[i+1:]`?

Example: `w = "hot"` and `i = 1`.

| Variable | Value | Meaning |
|---|---|---|
| `left` | `"h"` | Characters before index 1 |
| `ch` | `"a"` | Replacement character |
| `right` | `"t"` | Characters after index 1 |

Combining the parts:

`"h" + "a" + "t" = "hat"`

Only one character changes, while the other characters remain the same.

## Code

```python
from collections import deque

class Solution:
    def ladderLength(
        self,
        beginWord: str,
        endWord: str,
        wordList: list[str]
    ) -> int:

        words = set(wordList)

        if beginWord == endWord:
            return 1

        if endWord not in words:
            return 0

        que = deque([(beginWord, 1)])
        visit = {beginWord}

        while que:
            w, step = que.popleft()

            if w == endWord:
                return step

            for i in range(len(w)):
                left = w[:i]
                right = w[i+1:]

                for ch in "abcdefghijklmnopqrstuvwxyz":
                    value = left + ch + right

                    if value in words and value not in visit:
                        que.append((value, step + 1))
                        visit.add(value)

        return 0
```

## Key Takeaways

- **Why BFS?** BFS finds the shortest transformation sequence because it explores words in increasing order of sequence length.
- **Why a set?** Checking whether a word exists in a set is efficient.
- **Why `visited`?** Prevents revisiting words and processing them repeatedly.
- **Why mark visited when adding to the queue?** Ensures a word is not added multiple times.
- **Why `step = 1`?** The sequence counts both `beginWord` and `endWord`.
- **Why change one character at a time?** Every valid transformation must differ from the previous word by exactly one character.
- **Why return `0`?** The problem requires `0` if no valid transformation sequence exists.

## Complexity

Let:
- `N` = number of words in `wordList`.
- `L` = length of each word.

**Time:** Approximately `O(N × L × 26 × L)`, or `O(N × L²)`, because each word may require trying 26 characters at each position, and creating each new string takes up to `O(L)` time.

**Space:** `O(N × L)` for storing the words, visited set, and BFS queue.
