## 886. Possible Bipartition

Pattern: Graph + BFS + Two-Coloring

### 1. Approach

- Build an adjacency list from `dislikes`.
- Initialize `color = [-1] * n`.
- Use two colors: `0` and `1` representing two groups.
- Iterate through every person to handle disconnected components.
- Start BFS from each unvisited person and assign color `0`.
- For every neighbour:
  - If unvisited, assign the opposite color and add to queue.
  - If already colored with the same color as the current person, return `False`.
- If no conflicts exist, return `True`.

### 2. Pseudocode

```
Build adjacency list
Initialize color array with -1

For every person:
    If already visited:
        Continue

    Assign color 0
    Add person to queue

    While queue is not empty:
        Remove person u

        For each neighbour:
            If unvisited:
                Assign opposite color
                Add neighbour to queue

            Else if same color as u:
                Return False

Return True
```

### 3. Code
```

from collections import defaultdict, deque

class Solution:
    def possibleBipartition(self, n: int, dislikes: list[list[int]]) -> bool:

        # Step 1: Build adjacency list
        adj = defaultdict(list)

        for u, v in dislikes:
            adj[u].append(v)
            adj[v].append(u)

        # Step 2: Initialize colors
        color = [-1] * n

        # Step 3: Traverse every connected component
        for start in range(1, n + 1):

            if color[start - 1] != -1:
                continue

            color[start - 1] = 0
            queue = deque([start])

            # Step 4: BFS coloring
            while queue:
                u = queue.popleft()

                for neigh in adj[u]:

                    if color[neigh - 1] == -1:
                        color[neigh - 1] = 1 - color[u - 1]
                        queue.append(neigh)

                    elif color[neigh - 1] == color[u - 1]:
                        return False

        return True
```

### 4. Complexity Analysis

Let V = number of people and E = number of dislike relationships.

| Complexity      | Explanation                              |
| --------------- | ---------------------------------------- |
| Time: O(V + E)  | Build adjacency list + BFS traversal     |
| Space: O(V + E) | Adjacency list + color array + BFS queue |

### 5. Essentials to remember

1. Bipartition means dividing vertices into two independent groups.
2. Disliked people must belong to opposite groups.
3. `-1` = unvisited, `0` = Group 1, `1` = Group 2.
4. `1 - color[u-1]` assigns the opposite group.
5. Same-colored adjacent nodes → Conflict → `False`.
6. Outer loop handles disconnected components.
7. No need to construct a separate graph representation beyond the adjacency list.
